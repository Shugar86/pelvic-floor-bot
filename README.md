## Что это

**Навигатор тазового дна** — благотворительный проект для женского здоровья. Это набор простых инструментов, которые помогают спокойно разобраться в теме без паники, стыда и навязанных услуг.

- 🤖 **Telegram-бот** — анонимный навигатор по симптомам и безопасным маршрутам.
- 🖥️ **Лендинг** (Next.js) — одностраничник с объяснением проекта.
- 📄 **PDF-памятка** — шаблон «Красные флаги и 3 безопасных шага».
- 📓 **Трекер привычки** — 5-минутный дневник упражнений и дыхания.
- 📝 **Генератор вопросов к врачу** — чек-лист на основе симптомов.
- 💬 **Симптом-разбор** — бот объясняет возможные причины понятным языком.

### Для кого

- Для женщин, которым неловко задавать такие вопросы вслух и нужен спокойный первый шаг.
- Для тех, кто хочет понять, когда «можно подождать», а когда — пора к врачу.
- Для специалистов и волонтёров, которым нужен бережный материал для пациенток.

---

## ⚠️ Важно: бот не ставит диагнозы

Навигатор не заменяет врача. Он лишь помогает сориентироваться и разделяет ситуации на три маршрута:

- ✅ **Зелёный** — можно начать с самообразования и мягких практик.
- 🔶 **Жёлтый** — стоит обсудить с гинекологом или урологом.
- 🔴 **Красный** — не тянуть, нужна консультация врача.

## Быстрый старт

### Бот

```bash
cd bot
pip install -r requirements.txt
cp ../.env.example .env      # заполни BOT_TOKEN и OPENROUTER_API_KEY
python main.py
```

### Сайт

```bash
cd web
cp .env.local.example .env.local
npm install
npm run dev
```

## Характер проекта

**Вайб:** `caring` — забота без давления.

1. **Спокойный тон.** Никакой паники и громких заголовков — только понятные слова.
2. **Анонимность.** Не спрашиваем лишнего и не храним персональные данные.
3. **Честность.** Бот не лечит и не пугает; когда нужно — мягко направляет к специалисту.
