# 🌿 Навигатор тазового дна

> Благотворительный проект. Без диагнозов. Без стыда. Без рекламы.

## Что это

Простой набор инструментов для базового самообразования по теме тазового дна:

- **Telegram-бот** — анонимный навигатор по симптомам и маршрутам
- **Лендинг** (Next.js) — одностраничник с объяснением проекта
- **PDF-памятка** — шаблон «Красные флаги и 3 безопасных шага»
- **Трекер привычки** — 5-минутный дневник упражнений/дыхания
- **Генератор вопросов к врачу** — чек-лист на основе симптомов
- **Симптом-разбор** — бот объясняет возможные причины понятным языком

## Стек

| Часть | Технология |
|---|---|
| Bot | Python + python-telegram-bot + OpenRouter API |
| Landing | Next.js 14 + Tailwind CSS |
| PDF | jsPDF или @react-pdf/renderer |
| Деплой бота | Railway / Fly.io / VPS |
| Деплой сайта | Vercel |

## Структура

```
├── bot/                  # Telegram-бот
│   ├── main.py
│   ├── handlers/
│   ├── scenarios/
│   └── texts/
├── web/                  # Next.js лендинг + UI
│   ├── app/
│   ├── components/
│   └── public/
├── pdf/                  # PDF-памятка (шаблон)
├── shared/               # Общие тексты, константы
└── .env.example
```

## Быстрый старт

```bash
# Бот
cd bot
pip install -r requirements.txt
cp ../.env.example .env  # заполни BOT_TOKEN и OPENROUTER_API_KEY
python main.py

# Сайт
cd web
npm install
npm run dev
```

## Важно

Бот **не ставит диагнозы**. Он разделяет сценарии на три маршрута:
- ✅ Можно начать с самообразования и мягких практик
- 🔶 Стоит обсудить с гинекологом / урологом
- 🔴 Не тянуть — нужна консультация врача
