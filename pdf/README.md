# PDF-памятка

В этой папке хранится PDF-файл `pamyatka.pdf`, который бот отправляет пользователям.

## Содержание памятки

1. **Красные флаги** — когда нужно обратиться к врачу без промедления
2. **3 безопасных базовых шага** — дыхание, осанка, осознанность
3. **Вопросы к врачу** — краткий чек-лист для первого приёма

## Как создать PDF

Можно использовать:
- Canva (шаблон `pamyatka_template.canva` в этой папке)
- `@react-pdf/renderer` — компонент в `web/components/Pamyatka.tsx`
- Любой PDF-редактор

## Цвета (фирменный стиль)

- Основной акцент: `#21D4B0`
- Вторичный: `#22C0A0`
- Фон: `#FFFFFF`, `#F5F4F6`
- Текст: `#444445`
- Вторичный текст: `#A1A1AE`
